API Setup

  1. Go to Google Cloud Console → Places API (New) and Enable it (free tier includes monthly credit).
  2. Create an API key under Credentials.
  3. Paste it into the GOOGLE_PLACES_API_KEY line in the project's .env file.
  4. Restart this server (uv run python server.py).
  5. Ollama must be running locally with gemma4 pulled: ollama run gemma4
